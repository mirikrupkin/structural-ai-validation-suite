# 🧬 Structural AI & Validation Suite: HIV-1 Reverse Transcriptase

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/YOUR-USERNAME/structural-ai-validation-suite/blob/main/hiv_rt_pipeline.ipynb)

An interactive, end-to-end computational biology pipeline for extracting experimental reference chains from RCSB PDB (`1REV`), executing AI-driven multimer structure predictions via ColabFold, and rendering side-by-side 3D structural comparisons using `py3Dmol`.

---

## ✨ Key Features
- **Automated PDB Parsing:** Queries the RCSB database, extracts experimental chain sequences, and formats them for multi-chain complex predictions.
- **ColabFold Multimer Integration:** Automates sequence-to-structure prediction pipelines for viral protein complexes (such as the HIV-1 RT p66/p51 heterodimer).
- **Interactive 3D Visualizer:** Renders synchronized side-by-side views comparing AI-generated prediction models against experimental crystal structures, colored by pLDDT confidence scores.
